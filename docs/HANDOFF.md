## 한 줄

솔라시티 비어페스티벌 부스용 **로그인 없는 iPhone Safari 웹앱**. QR → 질문 3개(릴스) → 로딩 → 오늘 한 잔 추천 → 지도 → 카드.

제품 이름 화면: `How many drinks are too many drinks?` / 버튼 `スタート`.

- 병 누끼에서 뚜껑·병을 자르지 말 것.
- 키를 코드·채팅에 넣지 말 것. `XAI_API_KEY` 환경변수만. (지금은 Fast 코드 없음)

## 사용자 흐름

1. `/` 인트로. `drinks`만 SquigglyText로 일렁임. `スタート`는 pill, 누르면 살짝 스케일.
2. 같은 자리에서 로딩 `LoadScreen`. RollingText: `グラスを置く。` → `泡が立つ。` → `今夜、はじまる。` / 아래 `今夜の一杯`.
3. 로딩이 **그린 다음** 영상을 받는다 (`warmupPath`). 첫 질문 앞 3클립이 오면 `/q/1`.
4. 질문 3장. 세로 릴스(인스타처럼 꽉). 루프 스크롤. 글자 아래 그라데이션. 브라우저 크롬과 영상 위아래 색을 맞춤.
   - はじまり `心の向くまま歩くなら、どんな道？` — ホップの / フルーティーな / 爽やかな / モルトの / 華やかな
   - さかり `ひと休みするなら、どんな一杯？` — ほのかな甘み / ほろ苦い
   - なごり `帰り道、どんな音楽に包まれたい？` — なめらかな / 柔らかな / 優しい / 爽やかな / まろやかな
5. 마지막 `今夜は、これで。` → 큐레이션(RollingText) → 결과 `/r`.
6. 결과 스크롤 한 장:
   - 추천 병 + 이름(세이지, 병 아래가 글자를 가림) + 한 줄 + 장소
   - 고른 셋
   - 부스 지도 5×5. 現在地 좌상, 販売所 우하 두 칸, 빈칸은 연한 면. 대각 최단 선.
   - `つぎの一杯` 2잔. 부스 번호 `4-2`는 **이 리스트에 없음.**
   - `カードを受け取る` → 기기에서 카드 3장 (絵 / ことば / 場所). **추천된 그 병 PNG.**
   - `もう一度`

로그인 없음. 개인정보 없음. 답은 sessionStorage.

## 추천 로직 (Fast 없음)

논문: 北島・酒井, 상품설명문의 クラフトビール 특징, 감성공학회 22(4).

- 선택지 `keys` = 논문 단어+빈도.
- 맥주 `copy`/`source.text`에서 같은 단어를 센다 (`lexicon.ts`).
- 향·맛·입안 **층마다 코사인 후 평균.** 향 단어가 많아서 입안이 안 먹히게.
- 1위가 추천. 2·3위가 つぎの一杯.
- 화면에 나가는 한 줄은 **정본 `item.line`.** AI 생성 아님.

데이터 설명: [`BEERS.md`](BEERS.md).

## 영상

## UX 디테일 (건드리면 화남)

- START: `Button variant="pill"` `active:scale-[0.98]`. 누르면 `flushSync`로 로딩 먼저.
- 로딩 글자 위치: 인트로 제목과 같은 가운데 + 아래 `今夜の一杯` (7.5rem 하단 여백).
- 릴스: 영상 풀블리드, 텍스트 아래 그라데이션, 선택 버튼은 브라우저 바와 같은 그룹으로 아래.
- 결과 첫 장: 이름은 위, 병이 글자를 조금 가림. 스크롤 시 chromatic (병 RGB 번짐, `--ca` 최대 6.4).
- 긴 일본어 한 줄은 `、`에서 개행 (`wrap-ja.ts`). 카드 캔버스도 같음.
- 카드 3장 모두 종이 위 + **그 잔의 `item.art`**.
